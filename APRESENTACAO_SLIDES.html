Parte 2 · Deploy e segurança

Produção sem vazar credenciais

  • HTTPS real: frontend no GitHub Pages, API no Render (/actuator/health = UP).
  • Chave no servidor: GEMINI_API_KEY só nas variáveis do Render; nada no front ou no Git.
  • Chaves de cliente: geradas por POST /api/auth/api-keys, guardadas como SHA-256; a bruta aparece só na criação.
  • Rate limit por IP com Retry-After; X-Forwarded-For só com proxy confiável.
Segurança4 / 10
Parte 2 · Engenharia de prompt

Regras que evitam alucinação

  • Prompt de sistema: papéis claros, resposta em pt-BR, tom de estilista, escopo limitado ao universo Barbie.
  • Saída estruturada: schema JSON (título, resumo, paleta, itens, acessórios, prompt de imagem).
  • Dados reais: só acessórios que pertencem à Barbie escolhida; nada inventado.
  • Prompt de imagem: fotografia editorial realista, peças do próprio look, sem texto/logo/marca d'água.

Parte 3 · Demonstração ao vivo

Fluxo completo no navegador

  1. Abrir a aplicação pública e selecionar uma Barbie + ocasião.
  2. Gerar look → título, paleta, itens, acessórios reais e foto.
  3. Dicas aprimoradas → refina o mesmo look, sem recriar.
  4. Outra imagem → nova pose/foto do mesmo visual.
  5. Copiar look → texto pronto para uso.

No Swagger: POST /api/ia/assistente-estilo mostra promptImagem, aviso e avisoImagem.

Parte 4 · Resiliência e limites

Três camadas, nenhuma tela travada

TextoGemini → se 429, LookLocalClient usa o acervo real e avisa no campo aviso.
FotoGemini → Pollinations/FLUX (foto realista) → SVG determinístico. avisoImagem diz qual foi usado.
FrontendSpinner, timeout 120 s (IA 240 s), retry, mensagens amigáveis para 401/403/429/503/5xx/rede.

Validação: formulários obrigatórios, maxlength, limite de caracteres e imagem sem sentido descartada.

Resiliência7 / 10

Parte 5 · Limitações com transparência

O que é honesto dizer

  • H2 em memória: dados e chaves voltam ao estado inicial a cada restart.
  • Plano free do Render: suspende com inatividade — acessar a URL ~2 min antes da banca.
  • Tier gratuito do Gemini: cota de imagem = 0; por isso a foto realista via FLUX e o SVG entram como fallback.
  • Contexto: cada look é enviado como contexto explícito para as dicas; não acumulamos histórico ilimitado na LLM.
